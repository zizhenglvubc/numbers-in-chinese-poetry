本项目源自 Zizheng Lv 于 2026 年 7 月在北京大学交换项目期间所做的一次数字人文研究展示。语料扫描、统计代码与分析均由本人完成。本仓库重建该分析，公开代码与派生统计数据，并归档展示材料。

---

## 研究问题

数字在中国古典诗歌里到底出现得有多频繁？从唐到清，不同时期、不同文体之间有没有差别？

出发点是一个文学观察：一些名篇里数字分量很重，杜甫《石壕吏》的「三男邺城戍」，柳宗元《江雪》的「千山鸟飞绝，万径人踪灭」，李白《月下独酌》的「对影成三人」。问题在于，这个印象放到大规模语料里还站得住吗，还是只是选本造成的错觉。

## 方法

一首诗只要正文里出现下列任一字符，就计为「含数字」：

```
一 二 三 四 五 六 七 八 九 十 百 千 万 萬 亿 億 两 兩 零 廿 卅
```

判定用集合交集 `set(正文) & 数字字符集`，并以正则匹配交叉验证。**统计单位是「首」**，一首里出现一个数字和出现二十个，都只计一次。

运行：

```bash
python3 src/numeral_scan.py --corpus /path/to/chinese-poetry --out results/
```

## 结果

**175,355 首里有 59.24% 含至少一个数字字符**（103,885 首）。

![含数字的篇占比](figures/fig1_poem_level_rate.png)

| 集子 | 首数 | 含数字 | 占比 |
|---|---:|---:|---:|
| 唐诗 | 57,603 | 31,552 | 54.8% |
| 五代诗词 | 543 | 250 | 46.0% |
| 宋诗（1/3 抽样） | 84,984 | 50,171 | 59.0% |
| 宋词 | 21,053 | 15,022 | 71.4% |
| 元曲 | 10,914 | 6,705 | 61.4% |
| 清词（纳兰） | 258 | 185 | 71.7% |
| **总计** | **175,355** | **103,885** | **59.24%** |

有两点值得注意。词的两组都排在高位（71.4% 和 71.7%），诗的两组偏低（54.8% 和 59.0%），文体的区分度看起来比时代更明显。另外，「一」在每一组里都是第一高频数字，而且差距很大，唐诗里出现 20,277 次，第二名「三」只有 9,024 次。

### 扩展分析（2026 年 9 月）

以下两项是整理本仓库时补做的，不属于 2026 年 7 月展示的内容。

**字符级占比。** 数字字符占全部 11,571,489 字的 **2.15%**，而且各组之间非常平（1.36%–2.23%）。篇占比差异很大，但一段文本内部的数字密度几乎不动。

![数字字符占比](figures/fig2_character_level_rate.png)

**约数与不定量词。** 把 `半 双 雙 几 幾 数 數 无 無` 加进字符集，篇占比从 59.24% 升到 **73.4%**，而且原占比越低的组升得越多，五代从 46.0% 升到 72.6%。

```bash
python3 src/numeral_scan.py --corpus /path/to/chinese-poetry --out results/ --mode extended
```

## 哪些是统计事实，哪些是解释

统计结果：上面的计数、占比和频次排序。它们由语料和字符集决定，任何人用同一批文件跑同一份脚本都会得到同样的数字。

解释：数字在诗里作证（「三男邺城戍」）、定尺度（「千山」对「孤舟」）、结关系（「对影成三人」）、承载文化记忆（「八百里」用《世说新语》典）。这些来自对具体作品的细读，不是从计数里推出来的。脚本分不出《石壕吏》里的家庭账目、《江雪》里的大小对照和《月下独酌》里的关系变化。

## 限制

- 宋诗一组是《全宋诗》的 1/3 抽样，不是全集。
- 清代只有纳兰性德一家，258 首。
- 字符集覆盖的是整数。约数与不定量词在扩展模式里单独统计。
